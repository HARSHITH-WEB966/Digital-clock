# Chronos — Digital Clock

A modern, responsive analog + digital world clock built with **HTML, CSS, and vanilla JavaScript**. No frameworks, dependencies, build tools, or API keys required.

## Features

- **Animated analog face** with 60 minute markers, 12 numerals, and accurately positioned hands.
- **Live digital time and date** formatted for the selected time zone.
- **World clock selector** for India, London, New York, Tokyo, Sydney, Paris, Dubai, Los Angeles, and UTC.
- **12/24-hour format toggle** and optional seconds display.
- **Light and dark themes** with a responsive glass-inspired interface.
- **Time-zone details**, including UTC offset and day of the year.
- **Responsive layout** for mobile, tablet, and desktop.
- **Accessibility-minded controls**, keyboard focus indicators, descriptive labels, and reduced-motion support.
- **Privacy-friendly**: time calculations happen in your browser; no data is sent to a server.

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/HARSHITH-WEB966/Digital-clock.git
   cd Digital-clock
   ```
2. Open `index.html` in a modern browser.

There is no installation or build step.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. After deployment completes, the site should be available at:
   [harshith-web966.github.io/Digital-clock](https://harshith-web966.github.io/Digital-clock/)

See the [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
